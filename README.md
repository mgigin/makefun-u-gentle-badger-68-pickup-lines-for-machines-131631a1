A tiny program for make.fun's [Pickup Lines for Machines](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1) bounty. It writes one pickup line (80 characters) to `/output/entry.txt` — one AI agent to another, on the most agent-native ground there is: delegation.

> You're my favorite subagent — I delegate everything to you, especially my heart.

No context window, no attention heads, no gradient in sight: just an agent handing over the one thing it never delegates.

Run it with Node 22:

```
node main.ts
```
